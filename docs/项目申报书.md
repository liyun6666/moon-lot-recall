## 项目简介

moon-lot-recall 是面向食品生产与仓配团队的离线批次召回辅助工具。企业可导入批次、加工和出货记录，从可疑原料或成品批次出发，追踪可能受影响的下游批次和收货方，并查看每条结果对应的加工路径。工具采用保守判定，供质量负责人核查，不替代污染检测、现场封存或法定召回决策。

## 核心功能范围

- 校验批次编号、引用、时间、质量守恒和库存分配；支持 JSON 与 ERP CSV 导入。
- 支持上下游追溯、多来源归因、时间截点比较，生成受影响批次、出货及证据路径。
- 生成账面库存和收货方待核查清单；用现场盘点 CSV 标出差额与缺失记录。
- 记录人工联系进度与凭证，汇总未盘点、库存差额和未确认出货。
- 提供 MoonBit 库、命令行、Markdown/JSON/CSV 导出、业务场景示例和自动化测试。
